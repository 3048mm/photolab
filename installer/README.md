# Photolab の使い方

SD カードから写真を取り込むツールです。カードを挿すと自動で立ち上がり、
サムネイルを見ながら取り込む写真を選んで、日時をもとにリネームしてコピーします。

**同じ写真を二度取り込みません。** カメラのシリアル番号とショットカウントで
判定するので、カードを消さずに使い回しても、別のカードに同じカットが入っていても、
取り込み済みのものはグレーで表示されます。

**対応している形式**: Nikon（NEF）、Canon（CR2 / CR3）、Sony（ARW）の RAW と、JPEG、動画（MOV / MP4）。

> Canon と Sony の RAW は、ファイルからショットカウントを読み取れないため
> 「撮影日時 + 元のファイル名 + サイズ」で判定します。この判定には警告マークが付きます。
> カードをフォーマットしたあと、同じ日時・同じファイル名の別の写真を撮ることはまず無いので、
> 普段の使い方では問題ありません。

---

## はじめに（初回だけ）

### 1. 出力先の親フォルダを登録する

`出力先` の `＋` を押して、写真を置くフォルダを選びます（例 `D:\写真\Z6`）。

一度登録すれば、次からはボタン1つで切り替えられます。カメラごとに登録しておくと
`Z6` `Z50` のように並び、毎回フォルダを探さずに済みます。

### 2. 現像ソフトを選ぶ

画面下の `現像` で RapidRAW か darktable を選びます。
インストールされていない場合はグレーになります。

RapidRAW を後から入れる場合は、インストール先の `tools` フォルダにある
`install_rapidraw.ps1` を右クリック →「PowerShell で実行」してください。

---

## 取り込む

1. **カードを挿す** — 常駐していれば自動で開きます
2. **取り込むカットを選ぶ** — 最初は未取り込みだけにチェックが入っています
3. **フォルダ名を決める** — 撮影日を含む名前を提案します。既存フォルダも選べます
4. **［取り込み開始］**

取り込み中は［中断］で止められます。**途中まで取り込んだファイルは残ります。**
中断したカットは「未取り込み」のままなので、あとで取り込み直せます。

### 写真の選び方

| やりたいこと | 操作 |
| :--- | :--- |
| 範囲でまとめて選ぶ | 1枚目をクリック → Shift+クリックで最後の1枚 |
| 選んだものにチェックを付ける | ［選択をチェック］ |
| 1枚ずつ切り替える | チェックボックスをクリック |
| 全部 / 全解除 | ［すべて選択］［すべて解除］ |

**クリックしただけではチェックは変わりません。** 写真を拡大して確認しても、
それまでに付けたチェックは消えません。

### サムネイルの見方

| 表示 | 意味 |
| :--- | :--- |
| チェック | 取り込む対象 |
| 青い枠 | 選択中（操作の対象） |
| 白黒 + ✓ バッジ | すでに取り込み済み |
| `RAW+JPG` / `RAW` / `JPG` | そのカットの構成 |
| `▶ 0:14` | 動画と再生時間 |
| 黄色い △ | 撮影情報が読めず、重複判定が弱いカット |

### 日付ごとに分ける

1枚のカードに何日分も入っているときは、`日付ごとのフォルダに振り分ける` に
チェックを入れると `20260806 花火` `20260807 花火` のように分かれます。

## カードを挿したら自動で開く

インストール時に「ログイン時に常駐」を選んでいれば、通知領域（時計の近く）に
Photolab のアイコンが出ています。カードを挿すと自動で開きます。

アイコンを右クリックすると設定できます。

| 項目 | 内容 |
| :--- | :--- |
| Photolab を開く | カードが無くても開く |
| 自動検出 | 外すと、カードを挿しても反応しません |
| 検出したらすぐ開く | 外すと、通知だけ出ます（クリックで開く） |
| 終了 | 常駐をやめる |

**同じカードを挿しっぱなしにしても、開くのは1回だけです。** 抜いて挿し直せば
また開きます。

後から常駐をやめたい場合は、スタートアップから `Photolab 常駐` の
ショートカットを削除してください（`Win+R` → `shell:startup`）。

## 困ったとき

### 「取り込んだはずの写真が無い」と言われる

取り込んだ後にファイルを手で消すと、記録だけが残って「取り込み済み」の
ままになります。スタートメニューの `Photolab` フォルダから
`photolab-cli` を開き、次を実行してください。

```
photolab-cli doctor
```

食い違いが見つかったら `--fix` を付けて実行すると、**記録だけを消します**。
写真そのものは削除しません。消えたカットは「未取り込み」に戻ります。

### 現像ソフトに写真が出てこない

- **darktable** — すでに起動していると、後から開いても反映されません。
  一度終了してから取り込み直してください
- **RapidRAW** — 取り込み先フォルダを渡せない作りのため、RapidRAW 側で
  フォルダを開く必要があります
- どちらも、レーティングなどの絞り込みが効いていて表示されていないことがあります

### RAW と JPEG が両方出てくる

`JPEG も現像対象にする` のチェックを外すと、RAW があるフォルダでは
JPEG を現像ソフトに渡さなくなります（darktable のみ）。

### 起動しない

`%LOCALAPPDATA%\Photolab\error.log` に記録が残ります。

## データの置き場所

```
%LOCALAPPDATA%\Photolab\catalog.db     取り込み済みの記録
%LOCALAPPDATA%\Photolab\config.toml    設定
%LOCALAPPDATA%\Photolab\thumbnails\    サムネイルのキャッシュ
%LOCALAPPDATA%\Photolab\error.log      起動に失敗したときの記録
```

**アンインストールしてもこれらは消えません。** 取り込み済みの記録は写真と
対になって意味を持つため、消すと「取り込んだかどうか」が分からなくなります。
完全に消したい場合は上のフォルダを手で削除してください。
